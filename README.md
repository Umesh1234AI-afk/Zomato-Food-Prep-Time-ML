#  Zomato-Inspired Food Preparation Time Prediction

A Machine Learning regression project inspired by real-world food preparation time prediction use cases discussed by Zomato Engineering.

This project predicts the estimated food preparation time for an order using restaurant and order-related features.

---

##  Project Overview

Food preparation time is an important factor in food delivery platforms because it directly affects delivery estimates and customer experience.

In this project, a synthetic dataset was created using realistic features such as:

- Number of items
- Cuisine type
- Order hour
- Day of week
- Restaurant load
- Historical average preparation time

The target variable is:

- `food_preparation_time`

---

##  Important Note

This project does **not** use proprietary Zomato data.

The dataset is synthetic and was created for educational and portfolio purposes using feature ideas inspired by food preparation time prediction use cases discussed in Zomato Engineering.

Therefore, the model metrics represent performance on synthetic data and should not be interpreted as real-world Zomato production performance.
